# Депеша — сайт

Статический лендинг почтового клиента «Депеша» для домена depesha-app.ru. Сайт собирается на Astro (без UI-фреймворков и Tailwind) в папку `dist/` и отдаётся любым статическим хостингом.

Сам продукт описан в основном репозитории: https://github.com/fgbm/depesha

## Команды

- `npm run dev` — сервер разработки.
- `npm run build` — сборка статики в `dist/`.
- `npm run preview` — просмотр собранного сайта.
- `npm run check` — типы и разметка Astro (`astro check`).
- `npm run og` — пересобрать картинку для Open Graph `public/og.png`.
- `npm run shots` — снять собранный сайт (нужен `npm run build`) в `design/site-shots/`; падает с ненулевым кодом при ошибках консоли, нарушениях CSP или внешних запросах.
- `npm run overflow` — проверить горизонтальное переполнение на 320/360/375/412.

## Структура

- `src/layouts/Base.astro` — общий каркас: `<head>`, мета, меню, подвал, CSP.
- `src/pages/` — страницы: `index.astro` (главная), `privacy/` (политика конфиденциальности), `en/` (те же главная и политика по-английски), `404.astro`.
- `src/components/` — разделы главной: `Nav`, `Hero`, `Story`, `Shots`, `Sort`, `Palette`, `Servers`, `Never`, `Download`, `Footer`, `Reveal`.
- `src/lib/releases.ts` — разбор последнего релиза GitHub во время сборки.
- `src/styles/global.css` — токены, шрифты и стили разделов. Палитра — «Чернила» из приложения (0.8.12): холодный светлый фон, тёмно-синяя боковая панель, синий акцент. Знак (печать) остаётся красным.
- `public/` — ресурсы без сборки: `fonts/` (woff2 и лицензии OFL), `logo/`, значки, `og.png`, `robots.txt`.
- `assets/screenshots/` — кадры приложения для сайта: снимаются в репозитории приложения (`e2e/shots.mjs`, `e2e/meeting-shots.mjs`) и копируются сюда. Главное окно стоит в первом экране, остальные кадры — разделом «Приложение экранами»; страница собирает из них WebP и AVIF с PNG-запасом (`astro:assets`).
- `scripts/` — `og.mjs` (OG-картинка), `shoot-site.mjs` (скриншоты и проверки), `shoot-v2.mjs` (эталон макета).
- `design/mockups/v2/` — утверждённый HTML-макет и эталонные скриншоты.

## Правила

- Сайт на русском; английские `/en/` и `/en/privacy/` повторяют главную и политику для проверки OAuth у Google: ревьюеры читают по-английски. Языковые версии связаны `hreflang`.
- Никаких внешних ресурсов: шрифты и знак лежат в `public/`, кадры приложения собираются в `_astro/`, страница не ходит в сеть. Внешние ссылки — обычные `href` на github.com/fgbm/depesha, а в политике ещё на `myaccount.google.com` и `developers.google.com` (их требует Google).
- Ссылки на скачивание берутся из последнего релиза GitHub на этапе сборки; если API недоступен, они ведут на страницу релизов, а номер версии не показывается.
- Content-Security-Policy задаётся в `<meta>`; инлайновые скрипты Astro закрываются хешами. Сайт не использует cookie, аналитику и счётчики.
- Факты берутся из `README.ru.md` основного репозитория. Ничего сверх него не выдумывается.
- Тексты и вид утверждённого макета не меняются. Исключение — название «Депеша» строкой над заголовком главной: его сверяют с экраном согласия Google.

## Хостинг

Хостинг пока не выбран. Сайт — это статика из `dist/`: любые файлы кладутся на любой статический хостинг, домен depesha-app.ru.
