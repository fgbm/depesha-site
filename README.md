# Депеша — сайт

Лендинг почтового клиента «Депеша» для домена depesha-app.ru.

Здесь живут тексты и макеты, по которым сайт будет собираться. Продукт описан в основном репозитории: https://github.com/fgbm/depesha

## Что внутри

- `docs/brief.md` — бриф: аудитория, обещание, тон, действия, доказательства для блоков ниже первого экрана.
- `docs/copy-hero.md` — три варианта текста первого экрана с обоснованием угла.
- `design/mockups/hero/` — три HTML-макета первого экрана и страница-указатель `index.html` с открытыми вопросами.
- `assets/` — локальные шрифты (woff2 + лицензии OFL), скриншоты приложения, знак.

## Правила

- Сайт только на русском, аудитория русскоязычная.
- Никаких внешних ресурсов: шрифты, картинки и знак лежат в `assets/`, страницы не ходят в сеть.
- Факты берутся из `README.ru.md` основного репозитория. Ничего сверх него не выдумывается.
- Макеты в `design/mockups/` — это HTML без сборки, их достаточно открыть из файла.
